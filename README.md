# Estimaite-NEW-

The application lives on branch **`cursor/agile-estimator-mvp-cce6`** (pull request #1). This `main` branch does not contain the Next.js app.

```bash
git clone -b cursor/agile-estimator-mvp-cce6 https://github.com/ashish-vxii76/Estimaite-NEW-.git estimaite
cd estimaite
npm install
npm run dev
```

Then open **http://localhost:3456** on the same computer. Sign in with `admin@estimaite.local` / `demo1234`.
