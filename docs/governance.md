# Governance

Issue defaults: XL → REVIEW, XXL → SPLIT. Duration above one sprint also triggers REVIEW.

Epic defaults: ROM SP ≥ 120 → DECOMPOSE; ≥ 200 → SPLIT EPIC.

Readiness average < 0.4 → DISCOVERY REQUIRED; < 0.6 → SPIKE REQUIRED.

Approval: DRAFT → READY FOR REVIEW → REVIEWED → APPROVED, with RETURNED / REJECTED.

Manual override never deletes the automated SP. AI % defaults to 0.
